## Draghstple 🌿

 A personal website that works and looks like a WebOS but isn't a WebOS.

## Built With

- HTML
- CSS
- Vanilla JavaScript
- Spotify's official embed player
- Images from Unsplash

## Run It Locally

1. Download or clone this repository.
2. Keep the HTML file and its assets together as needed.
3. Open `index.html` in a modern browser.

No build step or package installation is required.
